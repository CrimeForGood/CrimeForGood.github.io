# crimeforgood.github.io

Source for the crimeforgood.xyz website. Static — no build step. Served by GitHub Pages
from the repository root; `CNAME` points it at crimeforgood.xyz.

Preview locally:

```sh
python3 -m http.server 8765   # then open http://localhost:8765
```
